# 大白话转Codex 使用教程（零基础版）

这个工具解决一个问题：你对 Codex 说的话太含糊（比如「把那个页面优化一下，再发布」），Codex 只能猜，结果经常改错东西或越界。
它会先指出你话里哪里不清楚，再让你补五项信息，最后生成一份边界清晰的指令，你复制给 Codex 就行。全程离线，不花钱，不调用任何模型。

## 第 0 步：准备

- 电脑上装好 Python 3.9 或更高版本（Windows 在命令行输入 `py -3 --version` 能看到版本号就行）。
- 下载本仓库（GitHub 页面点 Code → Download ZIP，解压）。不需要安装任何依赖。

## 方法一：最简单，用网页（推荐新手）

1. 打开解压后的 `web/index.html`（双击，用浏览器打开）。
2. 把你想对 Codex 说的话粘贴到最上面的大框里。页面会立刻列出哪里含糊、为什么会让 Codex 误解、建议怎么补。
3. 按提示填五项：目标、范围、禁区、成功标准、输出位置。
4. 点生成，复制生成的内容，粘贴给 Codex。也可以下载成 `.md` 文件。

网页不上传任何内容，断网也能用。

## 方法二：命令行

先在解压后的文件夹里打开命令行（Windows：在文件夹空白处按住 Shift 点右键，选「在终端中打开」）。下面 Windows 用 `py -3`，Linux/Mac 用 `python3`。

### 1. 体检：看你的话哪里含糊

```
py -3 -m codex_brief lint "把那个页面优化一下，再发布。"
```

实际会给出十几条提示，例如：

- 「那个」「优化一下」是模糊词，Codex 不知道改到什么程度。
- 没写目标、成功标准、范围、禁区、输出位置。
- 「发布」是高风险动作，需要先说明让谁确认。

### 2. 逐项问答，生成指令（最适合新手）

```
py -3 -m codex_brief interactive --out brief.md
```

按提示依次回答目标、范围、禁区、成功标准、输出位置，回车可以跳过。最后得到 `brief.md`。

### 3. 一条命令直接生成

```
py -3 -m codex_brief build "整理下载文件夹" --goal "把 input/ 里的文件按类型分到子文件夹" --scope "只读写 input/ 和 output/" --forbidden "不要删除任何文件，不要联网" --success "分完后列出每个文件去了哪，数量对得上" --output "output/整理结果.md，中文" --out brief.md
```

生成的 `brief.md` 里有：你的原话、五项信息，以及一组通用护栏（不乱猜、不编数据、删除发布前必须确认、先做一个样例再批量、验证后才能写「完成」等）。

## 五项信息怎么写

| 项目 | 问自己 | 好的写法 |
| --- | --- | --- |
| 目标 | 最后要得到什么？ | 生成一份按类别汇总的库存报告 |
| 范围 | Codex 只能看哪里、改哪里？ | 只读 input/，只写 output/ |
| 禁区 | 绝对不能碰什么？ | 不改原始数据，不发布，不联网 |
| 成功标准 | 怎么判断做完了、做对了？ | 每项数字都标来源，总数对得上 |
| 输出位置 | 结果放哪、什么格式？ | output/report.md，中文 Markdown |

小提示：不知道怎么填就留空，工具会标成「待补充」，不会替你瞎编。

## 把指令交给 Codex

最稳的做法：打开 `brief.md`，复制全部内容，直接粘贴到 Codex 的对话里。

想让工具帮你调用本机 Codex，可以先预览（默认只显示命令，不会执行）：

```
py -3 -m codex_brief send brief.md
```

确认没问题后，加 `--run` 才会真正启动 Codex（可能产生费用）：

```
py -3 -m codex_brief send brief.md --cwd . --sandbox workspace-write --run
```

## 常见问题

- **提示为零是不是就安全了？** 不是。这只是规则检查，不能保证 Codex 绝不越界，重要操作还是要自己看一眼。
- **报错找不到 Python？** Windows 用 `py -3`，Linux/Mac 用 `python3`。
- **文件已存在不覆盖？** 加 `--force` 才会覆盖。
- **想改检查规则？** 见 [docs/rules.md](rules.md)。
- **想看更多例子？** 见 [examples/README.md](../examples/README.md)。
